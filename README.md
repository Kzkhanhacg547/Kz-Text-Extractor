# Kz-Text-Extractor

Kz-Text-Extractor là một ứng dụng web giúp trích xuất văn bản từ các tệp tài liệu như **PDF, DOCX, DOC** bằng **Node.js, HTML, CSS**.

## 🚀 Tính năng
- Tải lên tệp **PDF, DOCX, DOC**.
- Trích xuất văn bản từ tệp đã tải lên.
- Hiển thị văn bản trích xuất trên giao diện web.
- Giao diện đơn giản, dễ sử dụng.

## 🛠 Công nghệ sử dụng
- **Backend:** Node.js, Express.js
- **Frontend:** HTML, CSS, JavaScript
- **Thư viện hỗ trợ:**
  - `multer` - Xử lý tải lên tệp
  - `pdf-parse` - Đọc nội dung PDF
  - `mammoth` - Trích xuất văn bản từ DOCX
  - `docx-parser` - Hỗ trợ đọc DOC

## 📥 Cài đặt và chạy dự án
### 1. Clone repository
```sh
git clone https://github.com/Kzkhanhacg547/Kz-Text-Extractor.git
cd Kz-Text-Extractor
```

### 2. Cài đặt dependencies
```sh
npm install
```

### 3. Chạy server
```sh
node index.js
```

Mở trình duyệt và truy cập `http://localhost:3000` để sử dụng.

## 📌 Cách sử dụng
1. Truy cập giao diện web.
2. Chọn tệp **PDF, DOCX, DOC** cần trích xuất.
3. Nhấn **Tải lên** và đợi hệ thống xử lý.
4. Xem kết quả văn bản trích xuất trên giao diện.
